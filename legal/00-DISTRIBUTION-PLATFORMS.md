# Distribution & platforms — CAVE AI PRO product family

## Google Play (Android)

The **CaveAI Pro** mobile application for **Android** is obtained through the **Google Play Store** (where the publisher lists it). Google Play distributes **Android packages only**; it does **not** install or run Windows desktop software.

## Windows (this application)

**CAVE AI PRO** is a **desktop application for Microsoft Windows** (64-bit Windows 10 / Windows 11 as defined in the installer and documentation). It is **not** distributed via Google Play and **cannot** run on Android.

Users who install CaveAI Pro from Google Play on a phone or tablet obtain the **Windows companion** from:

- **[Microsoft Store](https://apps.microsoft.com/)** (recommended for most Windows users — automatic Store updates), or
- **[www.caveaipro.com](https://www.caveaipro.com/#windows-download)** (Download for Windows — Velopack Setup.exe, MSI, or portable ZIP).

Android, Windows (Store and sideload), and the web Public Library are the active channels.

The sideload channel uses **Velopack Setup.exe** (automatic GitHub updates); MSI and portable ZIP may also be offered for advanced users. Store builds receive updates through the Microsoft Store only. See `docs/INSTALL.md` and `docs/MICROSOFT-STORE.md` in the Windows repo.

## Data workflow (high level)

1. Field work and backups on **Android** (app from **Google Play**).  
2. Copy **JSON** or **ZIP** backups to a **Windows** PC.  
3. Open them in **CAVE AI PRO** for analysis, exports, and printing.

## Store compliance

Play Store listings and screenshots should **not** imply that this PC/desktop MSI runs on Android or is downloaded from Google Play. PC materials should state **Microsoft Windows desktop only** and the correct acquisition path.
